## 浏览器覆盖

- 公共页面：中英文首页、工作台、图片入口、视频入口、积分说明、隐私政策、服务条款、博客、客座投稿；检查主文案、页面标题、导航、锚点、页脚和返回路径。
- 认证：中英文登录、注册、找回密码、无效重置链接；缺少邮箱的验证页、异常回跳、邀请兑换和认证回调；实际完成普通用户注册、错误密码登录、正确登录及退出。
- 普通账号：概览、创作工作室、资料、积分、账单、付款、工单支持。实际保存姓名，尝试头像上传并检查失败恢复；点击 14 个列表筛选标签，确认空列表状态；普通用户访问后台被拒绝，关闭的 API key 功能返回概览。
- 异常场景：阻断付款接口后显示错误和重试，恢复接口后可回到空列表；关闭投稿时新建入口不出现支付表单；缺少邮件和生成服务时显示真实状态。
- 模板：九个独立模板的中英文页面；检查原文提示词、复制反馈、“使用此模板”带入的模板及模式、返回模板库和关联模板地址。视频参考图明确标记为静态构图参考。
- 布局与主题：手机 390 px 的首页、工作台、移动菜单、用户侧栏；补测平板和桌面模板页，检查明暗主题与横向溢出。上一轮全站响应式和性能测量详见 `docs/launch-audit-2026-11-03.md`。

共享页头／页脚按两个语言版本验证，页面独有链接和动作单独验证。浏览器批量记录中的导航中断、开发热更新和自动化等待超时不作为产品缺陷或通过证据，失败项需以针对性复测记录为准。`mailto:` 只检查地址和链接，不实际发信。

## 数据与边界

一次性普通账号只用于注册、登录、资料及空状态测试，无生成、订单、积分充值或工单提交。账号已从共享 D1 按精确 ID 与保留测试邮箱双条件删除，复查剩余数量为 0；本地测试密码文件已移除。未改动已有超级管理员账号。

目前没有可用的 Fal 生成配置、头像存储和邮件发送服务，因此没有把真实生成成功、作品下载、头像持久化、邮件送达或支付闭环标记为通过。没有真实记录的订单、订阅、作品和工单详情状态，也不宣称已完整验收。普通用户无权进入的后台页面不属于本次用户旅程覆盖范围。

原始页面文案、链接结果、截图、账号清理凭据与测试日志在忽略目录 `data/user-journey/`。最终验证结果见本报告末尾。
