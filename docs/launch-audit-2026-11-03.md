## 性能数据

测量采用 Ego 的 Chrome DevTools Protocol 和 PerformanceObserver，并非 Lighthouse 评分。条件：本地 Node **生产构建**、独立 SQLite 测试库、390×900、缓存禁用、150 ms 网络延迟、200,000 B/s 下载（约 1.6 Mbps）、93,750 B/s 上传、4 倍 CPU 降速；各页面测量三次。初始对比已完成第一轮图片压缩，后续主要优化为资源预压缩、按需翻译和图片分片。

| 页面   | 优化前 LCP 中位数 | 最终 LCP 三次观测       | 最终中位数 | 最大 CLS |
| ------ | ----------------- | ----------------------- | ---------- | -------- |
| 首页   | 5.928 s           | 2.720 / 0.984 / 0.972 s | 0.984 s    | 0.000873 |
| 工作台 | 4.732 s           | 0.848 / 0.780 / 0.816 s | 0.816 s    | 0.000060 |

首页首次冷启动 TTFB 为 1.813 s，LCP 超出 2.5 s 目标；其余两次 TTFB 约 21 ms。生产域名上的 Cloudflare/D1 冷启动尚未实测。

移动菜单和图片/视频模式切换在 4 倍 CPU 降速下复测，Event Timing 最大观察值 104 ms。首次交互测试曾出现 1,040 ms 异常值，后续独立观察未复现；不能据此宣称真实用户 INP 已达标，部署后需持续采集。没有生成或支付真实订单来制造测试数据。

Nitro 预压缩依据：[官方资源压缩配置](https://nitro.build/config/assets#compresspublicassets)。
